## 启动顺序

### 正确的启动顺序（依赖链）

```
第 1 步: 基础设施
  ├── PostgreSQL (:5432)    — 必须先于 backend
  └── Redis (:6379)         — 可延迟，但建议先启动

第 2 步: 外部 AI 服务
  ├── OpenClaw Gateway (:8100)  — backend 初始化时会验证连通性
  └── GPT-SoVITS (:5000)       — 可选，没有也可以启动

第 3 步: C++ Backend (:8080 + :9001)
  └── 初始化时会:
      ├── 尝试连接 PostgreSQL → 失败则退出
      ├── 尝试连接 Redis → 失败则跳过 (warn)
      ├── 尝试验证 OpenClaw 连通性 → 失败则 warn
      ├── 启动 WebSocket 服务 (:9001)
      ├── 构建 Avatar 管线 (ServiceRegistry)
      └── 注册路由控制器

第 4 步: Vue 3 Frontend (:3000)
  └── 启动后用户访问 → WebSocket 连接到 backend :9001

第 5 步 (可选): Nginx (:80)
  └── 反向代理前端 + API
```

### Docker Compose 一键启动

```bash
# 完整启动 (含管理工具)
docker compose up -d

# 最小启动 (仅核心服务)
docker compose up -d postgres redis backend frontend nginx

# 带 GPT-SoVITS
docker compose up -d postgres redis backend frontend nginx gpt-sovits
```

### 启动后验证

```bash
# 1. 检查所有容器状态
docker compose ps

# 2. C++ 后端健康检查
curl http://localhost:8080/api/v1/health
# 期望返回: {"status":"ok","version":"1.0.0","uptime_seconds":...}

# 3. 前端可访问
curl -I http://localhost:3000
# 期望返回: HTTP 200

# 4. WebSocket 端口监听
ss -tlnp | grep 9001
# 期望: LISTEN 0.0.0.0:9001

# 5. GPT-SoVITS (如果部署了)
curl http://localhost:5000/
# 期望返回: 服务状态信息

# 6. OpenClaw 连通性
curl http://localhost:8100/v1/models
# 期望返回: 模型列表 JSON
```

## 用户发弹幕全流程

### 阶段 0: 用户进入直播间

```
1. 浏览器访问 /livestream
2. 路由守卫检查认证:
   ├── 未登录 → 重定向到 /?showLogin=true&redirect=/livestream
   └── 已登录 → 进入 LiveStream.vue

3. LiveStream.vue onMounted():
   ├── 注册 WS 事件回调 (onAvatar, onBroadcast, onError)
   ├── ws.connect(currentUser.id)
   │     ├── new WebSocket("ws://host:9001/ws")
   │     ├── onopen → sendMessage({type:"identify", data:{user_id, device_type}})
   │     └── onmessage → handleMessage() 分发到各回调
   └── ws.onConnectionStatusChange(true) → 显示 "已连接"
```

### 阶段 1: 用户输入 → 发送

```
浏览器 (前端)                              服务器 (后端 :9001)
───────────                               ──────────────────

用户输入 "你好八千代！"
  ↓
onInputLimit() 检查字数 (≤50 字符, Unicode 计数)
  ↓
用户点击 "发送"
  ↓
sendMessage():
  ├── isConnected? ✅
  ├── ws.sendUserMessage(content, userId, username, accessToken)
  │     ↓
  │   WebSocket.send(JSON) ────────────→  WebSocket 收到消息
  │                                       ↓
  │                                    WebSocketMessageHandler
  │                                    handleUserMessage(clientId, msg)
  │
  ├── chatRef.clearInput()
  └── isProcessing = true
```

### 阶段 2: 后端认证 + 审查 + 广播

```
WebSocketMessageHandler::handleUserMessage(clientId, message):
  │
  ├── 1. authenticateAndGetUserId()
  │     从 message.data.access_token 提取 JWT
  │     authService->getUserIdFromToken(token)
  │     ├── 有效 → userId = "123"
  │     └── 无效 → sendError("令牌无效") → return
  │
  ├── 2. 提取字段: text="你好八千代！", language="ja", senderName="ermaotie"
  │
  ├── 3. moderateAndPersist(userId, text, senderName, userIp)
  │     MessageServiceImpl::sendMessage(userId=123, text, ip, "websocket"):
  │       ├── 第1层: Redis 速率限制 → pass
  │       ├── 第2层: IP 黑名单检查 → pass
  │       ├── 第3层: 敏感词匹配 → pass
  │       ├── 第4层: DeepSeek AI 语义审核 → pass
  │       ├── 第5层: 行为分析 → pass
  │       ├── 第6层: 综合评分 → PASS (spamScore=0.05)
  │       └── INSERT INTO user_messages (user_id, original_message, review_status, ...)
  │     返回: msg->review_status = APPROVED
  │
  ├── 4. broadcastUserMessage(userId, senderName, text)
  │     json user_broadcast = {
  │       type: "user_broadcast",
  │       data: {sender_id:"123", sender_name:"ermaotie", content:"你好八千代！", timestamp}
  │     }
  │     for each connected_client:
  │       ws.sendToClient(client_id, user_broadcast)
  │     ↓
  │     所有在线观众收到消息 → 显示在消息列表
  │
  └── 5. processAvatarPipeline(clientId, userId, text, language)
          ↓
```

### 阶段 3: Avatar 管线

```
WebSocketMessageHandler::processAvatarPipeline():
  wsController->processUserMessage("456", "123", "你好八千代！", "ja")
    ↓
  WebSocketController::processUserMessage()
    ↓
  avatar_service_->processUserMessage("123", "你好八千代！", "ja")
    ↓
  AvatarResponseService::processUserMessage():
    │
    ├── [步骤 1] 内容二次审核
    │   moderation_service_->moderate({content: "你好八千代！"})
    │   → ModerationResponse {overallVerdict: "pass"}
    │   ├── block → 管线终止
    │   └── pass → 继续
    │
    ├── [步骤 2] OpenClaw AI 对话
    │   openClawGateway->processMessage("123", "你好八千代！")
    │     ├── 缓存检查 → 未命中
    │     ├── sendWithRetry(message):
    │     │     ├── 熔断检查 → 未触发
    │     │     ├── sendToOpenClaw():
    │     │     │     POST http://host:8100/v1/chat/completions
    │     │     │     Body: {model:"deepseek/deepseek-v4-flash",
    │     │     │            messages: [
    │     │     │              {role:"system", content:"你是月见八千代..."},
    │     │     │              {role:"user", content:"你好八千代！"}
    │     │     │            ], max_tokens:500}
    │     │     │     Headers: x-openclaw-model: deepseek/deepseek-v4-flash
    │     │     │           Authorization: Bearer ***
    │     │     │     ↓
    │     │     │     收到 OpenAI-format 响应:
    │     │     │     {choices:[{message:{content:
    │     │     │       '{"text":"你好呀神明大人！欢迎来到月读空间～",
    │     │     │         "emotion":"happy","action":"wave",
    │     │     │         "translation":"こんにちは神様！月読空間へようこそ～"}'}}]}
    │     │     │     → 成功, 耗时 750ms
    │     │     └── 更新熔断计数 → 0 (重置)
    │     │
    │     └── 解析:
    │           ├── parseJsonResponse(content) → 成功
    │           │   text: "你好呀神明大人！欢迎来到月读空间～"
    │           │   emotions: ["happy"]
    │           │   actions: ["wave"]
    │           │   translatedText: "こんにちは神様！月読空間へようこそ～"
    │           └── 缓存 (TTL=300s)
    │
    ├── [步骤 3] 文本翻译
    │   因为 openclawResponse.translatedText 不为空 且 targetLanguage="ja"
    │   → 直接使用 OpenClaw 内置翻译, 跳过外部 API
    │   finalText = "こんにちは神様！月読空間へようこそ～"
    │
    ├── [步骤 4] TTS 语音合成
    │   ttsService->synthesizeWithEmotion("こんにちは神様！...", "happy", DEFAULT)
    │     ├── 根据 emotion 选择参考音频: "reference/yachiyo_happy.wav"
    │     ├── POST http://localhost:5000/synthesize
    │     │   Body: {text:"こんにちは神様！...", text_language:"ja",
    │     │          emotion:"happy", voice_preset:"yachiyou_0",
    │     │          ref_audio_path:"reference/yachiyo_happy.wav"}
    │     │   ↓
    │     │   GPT-SoVITS 推理 (CPU ~5-15s, GPU ~0.5-2s)
    │     │   → {success:true, audio_url:"/audio/output_xxx.wav", duration_ms:3200}
    │     └── response.audioUrl = "http://gpt-sovits:5000/audio/output_xxx.wav"
    │         如果失败 → audioUrl = "" (静默降级)
    │
    ├── [步骤 5] 动画指令生成
    │   animationService->generateAnimationSequence(["happy"], ["wave"])
    │     ├── emotion "happy" → ExpressionCommand {name:"f_smile", durationMs:2000}
    │     ├── action "wave"  → ExpressionCommand fallback {name:"f_smile", durationMs:2000}
    │     │                 + MotionCommand {group:"TapBody", index:1, priority:1}
    │     │                   ⚠️ motion 文件缺失 → 前端会忽略 motion 命令
    │     └── animationCommands: [expression_cmd, expression_cmd, motion_cmd]
    │
    └── [步骤 6] 组装响应
        AvatarResponse {
          requestId: "resp_1234567890",
          text: "こんにちは神様！月読空間へようこそ～",
          originalText: "你好呀神明大人！欢迎来到月读空间～",
          emotions: ["happy"],
          actions: ["wave"],
          audioUrl: "http://gpt-sovits:5000/audio/output_xxx.wav",
          audioDurationMs: 3200,
          animationCommands: [...],
          processingTimeMs: 2525
        }
```

### 阶段 4: 响应推送 → 前端渲染

```
processAvatarPipeline() 返回后:
  │
  ├── ws.sendToClient(clientId, avatarResponse)
  │     只发给发送者
  │
  └── broadcast 给其他观众
        json broadcastAvatar = avatarResponse (附加 sender_client_id)
        for each client != sender: ws.sendToClient(clientId, broadcastAvatar)
```

```
浏览器 (前端)                              服务器 (后端)
───────────                               ──────────

WebSocket.onmessage:
  ↓
handleMessage(data):
  ↓
case "avatar_response":
  ↓
handleAvatarResponse(response):
  │
  ├── 1. chat.addAvatarResponse(response)
  │     消息列表追加 Yachiyo 回复
  │     role: "avatar", text: "こんにちは神様！...",
  │     emotions: ["happy"], audioUrl: "...", audioDuration: 3200
  │
  ├── 2. subtitle.startProgressive(fullText="こんにちは神様！...", duration=3200ms)
  │     ├── 逐字刻出: "こ" → "こん" → "こんに" → ...
  │     └── 约 30 个字符, 每个字符间隔 ~96ms
  │
  ├── 3. audio.play(response.audio_url)
  │     ├── AudioContext.createBufferSource()
  │     ├── AnalyserNode (用于口型同步)
  │     ├── audio.onMouth(callback):
  │     │     callback 在每帧被调用:
  │     │       analyser.getByteTimeDomainData()
  │     │       → RMS 音量计算
  │     │       → mouthOpenY = min(1.0, RMS * 4)
  │     │       → live2d.setSyncMouthOpenY(mouthOpenY)
  │     │       → Live2D SDK: coreModel.setParameterValueById("ParamMouthOpenY", value)
  │     │       → 模型嘴巴随音量开合
  │     └── audio.onEnd():
  │           ├── 嘴巴闭合 (mouthOpenY=0)
  │           ├── 字幕清除
  │           └── 表情恢复 f_smile
  │
  └── 4. playAnimations(response.animation_commands)
         for each cmd:
           ├── type="expression" → live2d.setExpression("f_smile", 2000)
           │    模型切换到微笑表情
           └── type="motion" → live2d.playMotion("TapBody", 1)
                ⚠️ motion 文件缺失 → 静默失败 (不影响其他功能)
```

### 阶段 5: 交互结束

```
T+0ms     用户点击发送
T+10ms    审查通过, 广播 user_broadcast → 消息列表显示 "你好八千代！"
T+750ms   OpenClaw 返回 JSON 响应
T+2525ms  管线完成, 推送 avatar_response
T+2530ms  前端收到: 显示回复文本 + 开始播放语音 + 显示字幕 + 切换表情
T+5730ms  语音播放完毕 (3200ms)
            → 嘴部闭合
            → 字幕清除
            → 表情恢复 f_smile (微笑)
            → 等待下一条弹幕
```

## 每条数据的形态转换

```
用户输入: "你好八千代！" (string, 前端 textarea)
    ↓ JSON.stringify()
  {"type":"user_message","data":{"content":"你好八千代！","user_id":"123","username":"ermaotie","access_token":"***","language":"ja"}}
    ↓ WebSocket.send() → 二进制帧 → WebSocket 收到
    ↓ json::parse()
  C++ json 对象: {"type":"user_message","data":{"content":"你好八千代！","user_id":"123",...}}
    ↓ 提取 text="你好八千代！"
    ↓ OpenClawGateway::sendToOpenClaw()
  OpenAI 请求 JSON: {model:"deepseek/deepseek-v4-flash", messages:[{role:"system",...},{role:"user",...}]}
    ↓ HTTP POST → OpenClaw Gateway
  OpenAI 响应 JSON: {choices:[{message:{content:'{"text":"你好呀...","emotion":"happy",...}'}}]}
    ↓ json::parse() → parseJsonResponse()
  OpenClawResponse DTO: {text:"你好呀神明大人！...", emotions:["happy"], actions:["wave"], translatedText:"こんにちは..."}
    ↓ TranslationService (使用内置翻译)
  finalText: "こんにちは神様！月読空間へようこそ～"
    ↓ GPTSoVITSService::synthesizeWithEmotion()
  TTS 请求: {text:"こんにちは...", text_language:"ja", emotion:"happy", ...}
    ↓ HTTP POST → GPT-SoVITS /synthesize
  TTS 响应: {success:true, audio_url:"/audio/output_xxx.wav", duration_ms:3200}
    ↓ Live2DAnimationService::generateAnimationSequence()
  animationCommands: [{type:"expression",params:{expression_name:"f_smile",...}}, ...]
    ↓ AvatarResponseService 组装
  AvatarResponse JSON:
    {type:"avatar_response", data:{
      text:"こんにちは神様！...",
      original_text:"你好呀神明大人！...",
      emotions:["happy"], actions:["wave"],
      audio_url:"http://gpt-sovits:5000/audio/output_xxx.wav",
      audio_duration_ms:3200,
      animation_commands:[...],
      processing_time_ms:2525
    }}
    ↓ WebSocket 广播 → 前端 JSON.parse()
  JavaScript 对象 → 分发到:
    ├── chat.messages[]       (文本消息)
    ├── subtitle.subtitleText (字幕)
    ├── audio.play()          (语音)
    └── live2d.setExpression() (表情)
```

## WebSocket 连接生命周期

```
客户端                                 服务器
───────                                ──────
new WebSocket("ws://host:9001/ws")
  ↓
CONNECTING 状态
  ↓
TCP 握手完成
  ↓
OPEN 状态
  ├── send({type:"identify", data:{user_id:"123"}})
  │     ↓                               → WebSocketController.handleClientConnect()
  │                                       ├── 创建 ClientSession {clientId, userId, connectedAt}
  │                                       └── 记录到 sessions_ map
  │     ← {type:"welcome", data:{client_id:456}}
  │
  ├── send({type:"user_message", data:{content:"你好", ...}})
  │     ↓                               → WebSocketMessageHandler.handleUserMessage()
  │                                       ├── 认证 → 审查 → 管线
  │                                       └── sendToClient(response) / broadcast
  │
  │  每 30 秒:
  │  ← {type:"ping"}                     ← WebSocketController 心跳
  │  → {type:"pong", data:{timestamp}}
  │
  │  用户关闭页面:
  │  ws.close()
  │     ↓                               → WebSocketController.handleClientDisconnect()
  │                                       ├── 标记 session.isAlive = false
  │                                       ├── 广播 "用户已离开"
  │                                       └── 清理 session
  │
CLOSED 状态
```

## 认证与鉴权链路

### REST API 认证

```
客户端请求:
  GET /api/v1/messages
  Header: Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
            ↓
  routes.cpp → BaseController::getAuthToken(req)
            ↓ 提取 token, 去掉 "Bearer " 前缀
  jwtUtil->verifyToken(token) → 验证签名 + 过期时间
            ↓
  jwtUtil->getUserId(token) → userId=123
            ↓
  authService->getUserById(123) → 检查用户是否存在/被禁用
            ↓
  放行 → Controller 执行
```

### WebSocket 认证

```
客户端: ws.send({type:"user_message", data:{access_token:"eyJ...", user_id:"123"}})
            ↓
WebSocketMessageHandler::authenticateAndGetUserId():
  1. 取 message.data.user_id → "123"
  2. 取 message.data.access_token
  3. authService->getUserIdFromToken(token)
     ├── 有效 → tokenUserId=123 → 覆盖 user_id 为 "123" (防伪造)
     └── 无效 → sendError("令牌无效") → return
```

### Token 刷新

```
客户端 Axios 拦截器:
  response.status == 401 →
    POST /api/v1/auth/refresh {refresh_token: "..."}
    → 后端: 验证 refresh_token → 生成新 access_token + 新 refresh_token
    → 前端: 更新 localStorage + Pinia
    → 重试原始请求
```

## 降级路径分析

| 失败点 | 检测方式 | 降级行为 | 用户体验 |
|--------|---------|---------|---------|
| Redis 不可用 | initializeServices() | 跳过缓存和速率限制 | 无影响, 仅无速率保护 |
| OpenClaw 不可达 | sendToOpenClaw() | 重试 2 次 → 熔断 30s → 返回错误 | "AI 服务暂时不可用" |
| OpenClaw 返回空 | rawContent.empty() | 返回错误 | "AI 服务返回空" |
| OpenClaw JSON 解析失败 | parseJsonResponse() | Fallback 到文本标签解析 | 透明降级 |
| 百度翻译 API 失败 | translateViaBaidu() | 切换到 DeepSeek LLM 翻译 | 稍慢, 效果相当 |
| DeepSeek 翻译也失败 | translateViaDeepSeek() | 返回原文 | 显示中文 (日语模型效果差) |
| GPT-SoVITS 不可用 | synthesizeWithEmotion() | audio_url="" | 有文字+动画, 无语音 |
| DeepSeek 审核不可用 | callDeepSeekAPI() | 本地规则审核 | 审核精度降低 |
| PostgreSQL 不可用 | initializeDatabase() | **启动失败, 退出** | 服务不可用 |

## 性能瓶颈分析

| 步骤 | 平均耗时 | 瓶颈类型 | 优化空间 |
|------|---------|---------|---------|
| 6层审查 | ~10ms | CPU | 小 |
| OpenClaw AI 对话 | ~800ms | 网络+LLM推理 | 中: 模型选择、max_tokens |
| OpenAI 内置翻译 | ~0ms | N/A | 免外部API调用 |
| GPT-SoVITS TTS (GPU) | ~1.5s | GPU推理 | 低: 已很快 |
| GPT-SoVITS TTS (CPU) | ~10s | CPU推理 | **高: 最大瓶颈** |
| Live2D 动画生成 | ~10ms | CPU | 小 |
| WebSocket 推送 | ~5ms | 网络 | 小 |
| **端到端总计 (GPU)** | **~2.5s** | TTS | 可接受 |
| **端到端总计 (CPU)** | **~11s** | TTS | 需优化或采用异步策略 |

### CPU TTS 延迟优化策略

如果只能 CPU 推理, 可以：
1. **文本先推送** → 前端先显示文字+字幕
2. **TTS 异步生成** → 后台继续合成语音
3. **语音就绪后推送** → 前端收到后立即播放

修改 AvatarResponseService 的步骤顺序：
```
旧: 审查 → OpenClaw → 翻译 → TTS(等待) → 动画 → 推送一条完整响应
新: 审查 → OpenClaw → 翻译 → 动画 → 推送文字响应(立即)
                └→ TTS(异步) → 推送语音响应(延迟)
```

## 故障排查思路

### 用户发送消息后无响应

```
检查顺序:
1. 前端 WebSocket 连接状态 → 看 connectionStatus 是否为 'connected'
2. 浏览器 DevTools → Network → WS → 看是否有 user_message 发出
3. 后端日志 → docker compose logs backend | grep -i error
4. OpenClaw 连通性 → curl http://localhost:8100/v1/models
5. 后端 processMessage 日志 → docker compose logs backend | grep OpenClaw
```

### Live2D 模型不显示

```
检查顺序:
1. 模型文件路径 → resources/live2d/yachiyo.model3.json 是否存在
2. Vite 代理配置 → 开发环境是否代理 /resources/live2d/
3. 浏览器 Console → 是否有 CORS 或 404 错误
4. 纹理文件 → yachiyo.8192/texture_00.png 是否存在
5. pixi-live2d-display → 是否报 "Failed to load model"
```

### 语音不播放

```
检查顺序:
1. GPT-SoVITS 是否运行 → curl http://localhost:5000/
2. TTS 合成是否成功 → docker compose logs gpt-sovits
3. audio_url 是否正确 → 查看 WebSocket 消息中的 audio_url
4. 浏览器 Console → 是否有 AudioContext 错误
5. 音频文件是否可访问 → 直接访问 audio_url
```

### OpenClaw 返回异常

```
检查顺序:
1. Gateway 是否运行 → curl http://localhost:8100/v1/models
2. auth_token 是否配置 → 检查环境变量 OPENCLAW_GATEWAY_TOKEN
3. System Prompt 是否正确 → 检查 backend/config/yachiyo_system_prompt.txt
4. OpenClawGateway 日志 → docker compose logs backend | grep OpenClaw
5. 熔断状态 → 日志中搜索 "熔断器触发" → 等待 30s 冷却
```

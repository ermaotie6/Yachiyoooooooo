# Yachiyo 项目要求

## 工作流程

### 登录与注册

首先要判断用户是否登录，如果没有登录的话进入登录界面，登录界面包含“昵称”“密码”两个文本框与“登录”“注册”两个按钮，注册时要填写“昵称”“邮箱”“密码”“确认密码”四块内容，确认密码与密码不同时要有提醒，昵称已存在时要有提示，登录界面密码错误、用户名不存在等情况也要有提示，注意防范SQL注入等攻击

### 直播页面

登录完成后进入主页面，主页面中包括“直播的视频窗口”“输入文本框”“实时消息框”等，因为只有一位主播所以不需要粉丝数什么的。直播的视频窗口大概包含“虚拟人物形象”“输出的文本”，输出的文本以字幕的形式根据语音刷新在直播窗口内的下方，字体等格式随意。输入文本框可以包含一些表情，有字数限制（50字），注意SQL注入等攻击。实时消息框包含了用户的昵称与发送的文本（包含表情）

### 直播工作流程

用户在输入文本框内输入文本并且点击发送后使用deepseek进行合法性判断，确认合法后以json文件的形式发送到指定接口与openclaw连接，并且把文本更新在实时消息框中，openclaw通过那一个端口返回了一个json文件后一方面文本通过百度翻译的api翻译为日语并且根据语音把文本更新在直播窗口底部的字幕，一方面文本与表情标签发送到GPT-SoVITS的指定接口并且输出一端语音，另一方面根据表情与动作实现live2d模型的对应，

## 注意事项

- 一定要做好安全防范，做好报错机制、数据库管理与日志记录
- 一些前端的设计安排尽量简洁一些，留出一些可以用图片替换的地方（比如说网站的logo与网页内部的背景）
- 再次检查live2d部分有没有什么问题，以防万一

## 🚀 立即行动计划

### 第一步: 环境准备 (1 小时)
```bash
# 1. 安装依赖
apt-get install build-essential cmake libcurl4-openssl-dev

# 2. 克隆项目
git clone <项目地址>
cd YachiyoCPP

# 3. 创建构建目录
mkdir build && cd build
```

### 第二步: 编译构建 (10 分钟)
```bash
# 1. 运行 CMake
cmake ..

# 2. 编译代码
make -j4

# 3. 查看输出
ls -la yachiyo_server
```

### 第三步: 数据库初始化 (5 分钟)
```bash
# 1. 创建数据库
createdb yachiyo_db

# 2. 执行迁移
psql yachiyo_db -f ../config/avatar_database_migration.sql

# 3. 验证表结构
psql yachiyo_db -c "\dt"
```

### 第四步: 配置系统 (5 分钟)
```bash
# 1. 编辑配置
cp ../config/avatar_config.yaml ./config.yaml
vi config.yaml

# 2. 设置关键参数:
# - database.host
# - database.password
# - openclaw.api_key
# - translation.api_key
```

### 第五步: 启动服务 (1 分钟)
```bash
# 1. 启动服务
./yachiyo_server --config config.yaml

# 2. 验证输出
# 应该看到: "Server running on port 8001"
```

### 第六步: 测试验证 (5 分钟)
```bash
# 1. 提交测试消息
curl -X POST http://localhost:8001/api/avatar/messages \
  -H "Content-Type: application/json" \
  -d '{"user_id":"test","message":"こんにちは"}'

# 2. 获取响应状态
curl http://localhost:8001/api/avatar/messages/{id}/status

# 3. 连接 WebSocket
wscat -c ws://localhost:8001/ws/avatar
```

**预计总耗时**: 30-45 分钟

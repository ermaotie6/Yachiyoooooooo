## 服务清单

| 服务 | 用途 | 必选 | 端点 |
|------|------|------|------|
| OpenClaw Gateway | AI 对话生成 (含情感+动作+翻译) | ✅ | `http://host:8100/v1/chat/completions` |
| GPT-SoVITS | 日语语音合成 (TTS) | 选 | `http://host:5000/synthesize` |
| 百度翻译 API | 日语翻译 (备选) | 选 | `https://fanyi-api.baidu.com/api/trans/vip/translate` |
| DeepSeek API | 内容审核 + 翻译备选 | 选 | `https://api.deepseek.com/v1/chat/completions` |
| PostgreSQL | 数据持久化 | ✅ | `localhost:5432` |
| Redis | 缓存 + 速率限制 | 选 | `localhost:6379` |

## OpenClaw 对接

### 架构

```
C++ Backend ──HTTP POST──→ OpenClaw Gateway /v1/chat/completions
             ←── OpenAI-format JSON ──
```

**无桥接层**。C++ 后端使用 `OpenClawGateway` 直连 OpenClaw 的 OpenAI 兼容 API。

### 配置

`backend/config/config.yaml`:
```yaml
openclaw:
  enabled: true
  api_endpoint: "http://host.docker.internal:8100"  # Docker 内
  # api_endpoint: "http://localhost:8100"           # 宿主机
  auth_token: "${OPEN…KEN}"            # Gateway 认证令牌
  model: "deepseek/deepseek-v4-flash"  # 使用的模型
  system_prompt_path: "/app/config/yachiyo_system_prompt.txt"
  request_timeout: 30
```

环境变量 (`docker-compose.yml`):
```yaml
- OPENCLAW_ENDPOINT=${OPENCLAW_ENDPOINT:-http://host.docker.internal:8100}
- OPENCLAW_GATEWAY_TOKEN=${OPEN…N:-}
- OPENCLAW_MODEL=${OPENCLAW_MODEL:-deepseek/deepseek-v4-flash}
```

### 请求/响应格式

Yachiyo 发送标准 OpenAI Chat Completions 请求：

```json
{
  "model": "deepseek/deepseek-v4-flash",
  "messages": [
    {"role": "system", "content": "<yachiyo_system_prompt.txt 内容>"},
    {"role": "user", "content": "你好八千代！"}
  ],
  "max_tokens": 500
}
```

加上自定义 header: `x-openclaw-model: deepseek/deepseek-v4-flash`

### System Prompt

文件位置: `backend/config/yachiyo_system_prompt.txt`

要求 OpenClaw 以 JSON 格式回复：
```json
{"text":"中文回复","emotion":"happy","action":"wave","translation":"日文翻译"}
```

可用 emotion: happy, excited, sad, angry, surprised, neutral
可用 action: wave, nod, shake, think, clap, heart, bow, idle

### 容错机制

| 机制 | 行为 |
|------|------|
| 重试 | 最多 2 次, 退避 1s / 3s |
| 熔断 | 连续 3 次失败 → 30 秒短路 |
| JSON fallback | JSON parse 失败 → 旧版文本标签解析 |
| 客户端错误 (4xx) | 不重试 |

## GPT-SoVITS 部署

### 前提

你已经在另一台电脑上完成了 GPT-SoVITS 模型训练（参考 [GPT-SoVITS部署指南.md](GPT-SoVITS部署指南.md) 第 1-2 节）。

### 第 1 步：从训练机拷贝文件

从 Windows 训练机拷贝以下文件到 Arch Linux 服务器。

**必有文件**（共约 500MB-1.5GB）：

```
Windows 训练机路径                        →  Linux 服务器路径
────────────────────────────────────────────────────────────────
GPT-SoVITS/logs/yachiyo/                  
  ├── yachiyo_e10_s400.pth               → /opt/yachiyo/sovits-models/
  └── yachiyo-e15.ckpt                   → /opt/yachiyo/sovits-models/

GPT-SoVITS/reference_audio/              
  └── yachiyo_ref.wav                    → /opt/yachiyo/sovits-models/reference/

(如果有多情感参考音频):
  └── yachiyo_happy.wav                  → /opt/yachiyo/sovits-models/reference/
  └── yachiyo_sad.wav                    → /opt/yachiyo/sovits-models/reference/
  └── yachiyo_angry.wav                  → /opt/yachiyo/sovits-models/reference/
```

**另外确保 GPT-SoVITS 预训练基础模型存在**（约 2GB）：

这些不是训练产物，而是 GPT-SoVITS 的基础模型，需要在推理服务器上也部署：

```
GPT-SoVITS/GPT_SoVITS/pretrained_models/
├── s1bert25hz-2kh-longer-epoch=68e-step=50232.ckpt  (~1.5GB)
├── s2D488k.pth                                       (~600MB)
└── s2G488k.pth                                       (~600MB)
```

> 这些文件在训练机的 GPT-SoVITS 安装目录下。如果没有，从 [HuggingFace](https://huggingface.co/lj1995/GPT-SoVITS) 下载。

**总上传量**: 约 2.5-3.5GB。

上传命令：
```bash
# 创建目录
ssh your-server "mkdir -p /opt/yachiyo/sovits-models/reference"

# 上传训练产物
scp yachiyo_e10_s400.pth your-server:/opt/yachiyo/sovits-models/
scp yachiyo-e15.ckpt your-server:/opt/yachiyo/sovits-models/
scp yachiyo_ref.wav your-server:/opt/yachiyo/sovits-models/reference/
scp yachiyo_happy.wav your-server:/opt/yachiyo/sovits-models/reference/  # 可选
```

### 第 2 步：安装 GPT-SoVITS

```bash
cd /opt
git clone https://github.com/RVC-Boss/GPT-SoVITS.git
cd GPT-SoVITS

# 创建虚拟环境
python -m venv venv
source venv/bin/activate

# CPU 模式（无 GPU）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

# 或者 GPU 模式（有 NVIDIA 显卡）
# pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# 安装项目依赖
pip install -r requirements.txt

# 安装 FFmpeg
sudo pacman -S ffmpeg  # Arch Linux
```

### 第 3 步：放置文件

```bash
# 训练产物
cp /opt/yachiyo/sovits-models/yachiyo_e10_s400.pth /opt/GPT-SoVITS/models/
cp /opt/yachiyo/sovits-models/yachiyo-e15.ckpt /opt/GPT-SoVITS/models/

# 参考音频
cp /opt/yachiyo/sovits-models/reference/*.wav /opt/GPT-SoVITS/reference/

# 预训练基础模型（从训练机拷贝或下载）
# 放入 /opt/GPT-SoVITS/GPT_SoVITS/pretrained_models/
```

### 第 4 步：启动 API

```bash
cd /opt/GPT-SoVITS
source venv/bin/activate

# CPU 模式
CUDA_VISIBLE_DEVICES="" python api.py \
  -s models/yachiyo_e10_s400.pth \
  -g models/yachiyo-e15.ckpt \
  -dr reference/yachiyo_ref.wav \
  -dt "你好，我是八千代辉夜姬" \
  -dl "zh" \
  -a 0.0.0.0 \
  -p 5000
```

### 第 5 步：验证

```bash
# 健康检查
curl http://localhost:5000/

# 测试合成 (日语)
curl -X POST http://localhost:5000/synthesize \
  -H "Content-Type: application/json" \
  -d '{"text":"こんにちは、八千代です","text_language":"ja"}' \
  --output test.wav

# 播放测试
aplay test.wav  # 或 ffplay test.wav
```

### 第 6 步：配置 Yachiyo

`backend/config/config.yaml`:
```yaml
gpt_sovits:
  enabled: true
  api_endpoint: "http://localhost:5000"
  mode: "cpu"         # "cpu" 或 "gpu"
  timeout_seconds: 60  # CPU 模式建议 60
```

`GPTSoVITSService.cpp` 已内置情感参考音频映射：
```
neutral/default → reference/yachiyo_ref.wav
happy/excited   → reference/yachiyo_happy.wav
sad             → reference/yachiyo_sad.wav
angry           → reference/yachiyo_angry.wav
```

如果某个情感没有对应的参考音频，自动 fallback 到 `yachiyo_ref.wav`。

### 第 7 步：加入 docker-compose（推荐）

```yaml
services:
  gpt-sovits:
    image: python:3.10-slim
    # ... (完整配置见 GPT-SoVITS部署指南.md 第5节)
    ports:
      - "5000:5000"
    volumes:
      - /opt/yachiyo/sovits-models:/app/models
      - /opt/yachiyo/sovits-models/reference:/app/reference
```

## 翻译服务配置

### 优先级

1. **OpenClaw 内置翻译** — System Prompt 要求返回 `translation` 字段，无需额外 API 调用
2. **百度翻译 API** — 速度快、费用低
3. **DeepSeek LLM 翻译** — 备选

### 配置

```yaml
translation:
  enabled: true
  default_language: "zh"
  services:
    - name: "baidu"
      appid: "${BAIDU_TRANSLATE_APPID}"
      api_key: "${BAID…KEY}"
      endpoint: "https://fanyi-api.baidu.com/api/trans/vip/translate"
      priority: 1
    - name: "deepseek"
      api_key: "${DEEP…KEY}"
      endpoint: "https://api.deepseek.com"
      priority: 2
```

### 获取百度翻译 API Key

1. 访问 https://fanyi-api.baidu.com/manage/developer
2. 注册 → 创建应用 → 获取 APPID 和密钥
3. 免费额度：每月 200 万字符

## 内容审核配置

```yaml
moderation:
  enabled: true
  deepseek_api_key: "${DEEPSEEK_API_KEY}"
  deepseek_api_endpoint: "https://api.deepseek.com"
  thresholds:
    violence: 0.8
    adult: 0.9
    harassment: 0.7
    spam: 0.6
    hate: 0.7
    profanity: 0.8
```

审核失败时自动回退到本地敏感词规则匹配。

## 全部环境变量一览

### 可在 `.env` 或 docker-compose environment 中设置

| 变量 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| `JWT_SECRET_KEY` | JWT 签名密钥 (≥32字符) | ✅ | - |
| `DB_PASSWORD` | PostgreSQL 密码 | ✅ | - |
| `OPENCLAW_GATEWAY_TOKEN` | OpenClaw 认证令牌 | 选 | - |
| `OPENCLAW_ENDPOINT` | OpenClaw 地址 | 选 | `http://host.docker.internal:8100` |
| `OPENCLAW_MODEL` | AI 模型 | 选 | `deepseek/deepseek-v4-flash` |
| `DEEPSEEK_API_KEY` | DeepSeek API Key | 选 | - |
| `BAIDU_TRANSLATE_APPID` | 百度翻译 APPID | 选 | - |
| `BAIDU_TRANSLATE_API_KEY` | 百度翻译密钥 | 选 | - |
| `SOVITS_ENDPOINT` | GPT-SoVITS 地址 | 选 | `http://localhost:5000` |

### 如何在生产环境设置

```bash
# 创建 .env 文件 (已在 .gitignore 中)
cat > .env << 'EOF'
JWT_SECRET_KEY=your-generated-random-32-char-string
DB_PASSWORD=your-secure-db-password
OPENCLAW_GATEWAY_TOKEN=sk-...
DEEPSEEK_API_KEY=sk-...
BAIDU_TRANSLATE_APPID=20150630000000001
BAIDU_TRANSLATE_API_KEY=your_baidu_key
EOF

# Docker Compose 自动读取 .env
docker compose up -d
```

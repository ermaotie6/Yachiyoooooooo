## 📌 重要笔记

### 为什么分离这些服务?

1. **OpenClaw 只负责文本处理**
   - 专注核心 AI 推理
   - 减少依赖复杂性
   - 便于替换 AI 模型

2. **DeepSeek 独立内容审查**
   - 可独立升级审查策略
   - 支持离线和在线模式
   - 易于 A/B 测试

3. **翻译服务独立**
   - 支持多个翻译引擎
   - 可根据语言对选择最佳引擎
   - 提高翻译质量

4. **语音合成独立**
   - GPT-SoVITS 是重量级服务
   - 可单独容器化部署
   - 支持声音克隆

5. **Live2D 独立**
   - 前端负责动画渲染
   - 后端只负责命令生成
   - 支持多种虚拱模型

## 1. 部署前必须亲自处理的事项

> ⚠️ **以下内容无法自动化，必须由你本人完成。**

| 服务 | 用途 | 获取地址 | 必要性 |
|------|------|----------|--------|

| **百度翻译 APP ID + API Key** | 翻译服务主引擎 | https://fanyi-api.baidu.com/manage/developer | ⭐ **必须** |
| OpenAI API Key | 可选 AI 对话引擎 | https://platform.openai.com/api-keys | 可选 |
| 千问 API Key | 可选 AI 对话引擎（国内） | https://dashscope.aliyun.com/api-key_create | 可选 |

### 1.2 必须准备的基础设施

| 项目 | 说明 |
|------|------|
| **Linux 服务器** | Arch Linux / Debian 12+ / Ubuntu 22.04+，最低 2C4G，推荐 4C8G |
| **域名** | 已托管到 Cloudflare，详见第 6 节 SSL 配置 |

### 1.3 必须决定的密码/密钥

部署时需设置，可在部署脚本交互中输入：

| 项目 | 说明 | 默认值（不安全） |
|------|------|-----------------|
| **PostgreSQL 密码** | 数据库密码 | `postgres` |
| **JWT Secret Key** | JWT 签名密钥，建议 ≥32 字符随机字符串 | `yachiyo-cpp-secret-key-change-in-production` |
| **Redis 密码** | Redis 访问密码 | 空（无密码） |

生成随机密钥：
```bash
openssl rand -hex 32    # JWT Secret
openssl rand -base64 24 # 数据库密码
```

## 3. Docker Compose 部署（推荐）

### 3.1 安装 Docker

**Arch Linux:**
```bash
sudo pacman -S docker docker-compose
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
# 重新登录使组生效
```

**Debian / Ubuntu:**
```bash
sudo apt-get update
sudo apt-get install -y ca-certificates curl gnupg
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/$(. /etc/os-release && echo "$ID")/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/$(. /etc/os-release && echo "$ID") \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
```

### 3.2 克隆项目

```bash
cd /opt
sudo git clone https://github.com/ermaotie6/yachiyoooooooo.git yachiyo
sudo chown -R $USER:$USER /opt/yachiyo
cd /opt/yachiyo
```

### 3.3 创建 .env 文件

```bash
cat > .env << 'EOF'
# ===== 必须修改 =====
JWT_SECRET_KEY=用openssl_rand_hex_32生成
DEEPSEEK_API_KEY=sk-你的DeepSeek密钥
BAIDU_TRANSLATE_APP_ID=你的百度翻译APPID
BAIDU_TRANSLATE_API_KEY=你的百度翻译密钥

# ===== 可选修改 =====
# POSTGRES_PASSWORD=postgres
# POSTGRES_USER=postgres
# POSTGRES_DB=yachiyo
EOF
```

### 3.4 配置 config.yaml

编辑 `config/config.yaml`，填入 API Key（所有敏感值支持 `${ENV_VAR}` 语法从环境变量读取）：

```yaml
ai:
  deepseek:
    api_key: "sk-你的DeepSeek密钥"
  translation:
    engines:
      - name: "baidu"
        app_id: "你的百度翻译APPID"
        api_key: "你的百度翻译密钥"
      - name: "deepseek"
        api_key: "sk-你的DeepSeek密钥"
  deepseek_moderation:
    api_key: "sk-你的DeepSeek密钥"

jwt:
  secret_key: "与.env中JWT_SECRET_KEY一致"

database:
  password: "与docker-compose中POSTGRES_PASSWORD一致"
```

### 3.5 启动服务

```bash
cd /opt/yachiyo

# 核心服务
docker compose up -d postgres redis backend frontend nginx

# 可选：监控
docker compose up -d prometheus grafana

# 可选：管理工具
docker compose up -d pgadmin redis-commander

# 全部启动
docker compose up -d
```

### 3.6 验证

```bash
docker compose ps
curl http://localhost:8080/api/v1/health
curl -I http://localhost:3000
docker compose logs -f backend
```

### 3.7 常用命令

```bash
docker compose down                    # 停止
docker compose down -v                 # 停止并清除数据⚠️
docker compose up -d --build           # 代码更新后重建
docker compose up -d --build backend   # 仅重建后端
docker compose logs -f backend         # 查看日志
```

## 5. 手动裸机部署

### 5.1 安装依赖

**Arch Linux:**
```bash
sudo pacman -S base-devel cmake ninja gcc git \
    openssl yaml-cpp postgresql-libs hiredis curl \
    nlohmann-json postgresql redis nginx nodejs npm
```

**Debian / Ubuntu:**
```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake ninja-build gcc g++ git \
    libssl-dev libyaml-cpp-dev libpq-dev libhiredis-dev libcurl4-openssl-dev \
    nlohmann-json3-dev pkg-config \
    postgresql postgresql-contrib redis-server nginx nodejs npm
```

### 5.2 初始化数据库

```bash
sudo systemctl enable --now postgresql
sudo -u postgres psql -c "CREATE DATABASE yachiyo;"
sudo -u postgres psql -c "ALTER USER postgres WITH PASSWORD '你的数据库密码';"
sudo -u postgres psql -d yachiyo -f /opt/yachiyo/database/init.sql
```

### 5.3 启动 Redis

```bash
sudo systemctl enable --now redis       # Arch
# sudo systemctl enable --now redis-server  # Debian/Ubuntu
```

### 5.4 构建后端

```bash
cd /opt/yachiyo/backend
mkdir -p build && cd build
cmake .. -G "Ninja" -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_STANDARD=20
ninja
```

### 5.5 构建前端

```bash
cd /opt/yachiyo/frontend
cp .env.example .env.local
# 编辑 .env.local：修改 VITE_API_BASE_URL 和 VITE_WEBSOCKET_URL 为你的服务器地址
npm ci && npm run build
```

### 5.6 创建 systemd 服务

```bash
# 创建运行用户
sudo useradd -r -s /bin/bash -m yachiyo
sudo chown -R yachiyo:yachiyo /opt/yachiyo

# 后端服务
sudo tee /etc/systemd/system/yachiyo-backend.service << 'EOF'
[Unit]
Description=Yachiyo Backend Service
After=network.target postgresql.service redis.service

[Service]
Type=simple
User=yachiyo
Group=yachiyo
WorkingDirectory=/opt/yachiyo/backend
ExecStart=/opt/yachiyo/backend/build/yachiyo_cpp --config-dir /opt/yachiyo/backend/config --env production
Restart=always
RestartSec=5
Environment=APP_PORT=8080
Environment=DATABASE_HOST=localhost
Environment=REDIS_URL=redis://localhost:6379

[Install]
WantedBy=multi-user.target
EOF

# 前端服务
sudo tee /etc/systemd/system/yachiyo-frontend.service << 'EOF'
[Unit]
Description=Yachiyo Frontend Service
After=network.target

[Service]
Type=simple
User=yachiyo
Group=yachiyo
WorkingDirectory=/opt/yachiyo/frontend
ExecStart=/usr/bin/npx serve -s dist -l 3000
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now yachiyo-backend yachiyo-frontend
```

### 5.7 配置 Nginx

```bash
sudo cp /opt/yachiyo/nginx.conf /etc/nginx/nginx.conf
sudo sed -i 's/server backend:8080/server localhost:8080/' /etc/nginx/nginx.conf
sudo sed -i 's/server backend:9001/server localhost:9001/' /etc/nginx/nginx.conf
sudo sed -i 's/server frontend:3000/server localhost:3000/' /etc/nginx/nginx.conf
sudo nginx -t && sudo systemctl enable --now nginx
```

## 6. Cloudflare SSL / HTTPS 配置

> 你的域名已经托管在 Cloudflare，按以下步骤配置 HTTPS。

### 6.1 Cloudflare DNS 设置

登录 [Cloudflare Dashboard](https://dash.cloudflare.com) → 选择你的域名 → DNS 记录：

| 类型 | 名称 | 内容 | 代理状态 |
|------|------|------|---------|
| A | `@` 或子域名 | 你的服务器公网 IP | ✅ 已代理（橙色云朵） |

> 开启代理后 Cloudflare 自动提供边缘 HTTPS，隐藏真实 IP，DDoS 防护 + CDN 加速。

### 6.2 SSL/TLS 模式

Cloudflare → SSL/TLS → 概述：

- 选择 **Full (Strict)**（推荐）— 需要在服务器安装 Origin Certificate
- 或选择 **Full** — 服务器可用自签证书

### 6.3 生成并安装 Origin Certificate

在 Cloudflare → SSL/TLS → Origin Server → **Create Certificate**：

1. 密钥类型: RSA (2048)
2. 主机名: 你的域名（如 `yachiyo.example.com`, `*.example.com`）
3. 有效期: 15 年
4. 点击 Create，**立刻复制** Origin Certificate 和 Private Key（Private Key 只显示一次！）

在服务器上安装：

```bash
sudo mkdir -p /opt/yachiyo/ssl

# 将 Origin Certificate 内容粘贴进去（-----BEGIN CERTIFICATE----- 开头）
sudo nano /opt/yachiyo/ssl/cert.pem

# 将 Private Key 内容粘贴进去（-----BEGIN PRIVATE KEY----- 开头）
sudo nano /opt/yachiyo/ssl/key.pem

# 设置权限
sudo chmod 600 /opt/yachiyo/ssl/key.pem
```

### 6.4 启用 Nginx HTTPS

编辑 `nginx.conf`，取消 SSL 相关注释：

```nginx
server {
    listen 80;
    server_name 你的域名;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name 你的域名;

    ssl_certificate /etc/nginx/ssl/cert.pem;
    ssl_certificate_key /etc/nginx/ssl/key.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # ... 其余 location 配置不变
}
```

Docker 模式下 `docker-compose.yml` 已将 `./ssl` 挂载到 `/etc/nginx/ssl`，只需将证书放入项目根目录的 `ssl/` 文件夹即可。

### 6.5 Cloudflare 其他推荐设置

| 设置位置 | 选项 | 推荐值 |
|----------|------|--------|
| SSL/TLS → Edge Certificates | Always Use HTTPS | ✅ 开启 |
| SSL/TLS → Edge Certificates | Minimum TLS Version | TLS 1.2 |
| SSL/TLS → Edge Certificates | Automatic HTTPS Rewrites | ✅ 开启 |
| Network | WebSockets | ✅ 开启（免费版默认已开启） |
| Speed → Optimization | Auto Minify | ✅ JS/CSS/HTML |

### 6.6 WebSocket 通过 Cloudflare

Cloudflare 免费版支持 WebSocket。注意事项：

- 前端生产环境使用 `wss://你的域名/ws`
- Cloudflare 免费版 WebSocket 空闲超时 100 秒，项目心跳间隔 30 秒（已满足）
- Nginx 中 `/ws` 路径已配置 WebSocket 升级头

## 7. 生产环境安全加固

### 必做清单

- [ ] 修改 PostgreSQL 默认密码
- [ ] 设置高强度 JWT Secret（≥32 字符）
- [ ] 设置 Redis 密码
- [ ] 修改 `config.yaml` 中 `cors_origins` 为你的域名（不要用 `*`）
- [ ] 配置防火墙，只开放 22/80/443

### 防火墙

```bash
# UFW (Debian/Ubuntu)
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

# iptables (Arch)
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT
sudo iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
sudo iptables -A INPUT -i lo -j ACCEPT
sudo iptables -P INPUT DROP
sudo iptables-save > /etc/iptables/iptables.rules
```

### 建议

- [ ] 关闭 pgAdmin / Redis Commander 的外部访问（或不启动）
- [ ] 将 Grafana 密码从 `admin` 修改为强密码
- [ ] 定期备份数据库
- [ ] 修改 `database/init.sql` 中管理员账户密码

## 8. GPT-SoVITS 语音合成部署

> GPT-SoVITS 是独立的 Python 服务，需要 NVIDIA GPU。完整详细指南见 `docs/GPT-SoVITS部署指南.md`。

### 8.1 需要准备什么

| 项目 | 说明 |
|------|------|
| **GPU 服务器** | NVIDIA RTX 3060+ (≥8GB VRAM)，可以是独立机器 |
| **CUDA** | 11.7+ 或 12.1+ |
| **Python** | 3.9~3.11（推荐 3.10） |
| **参考音频** | 八千代辉夜姬的清晰语音片段（2~15秒/条，总计 ≥10 分钟） |

### 8.2 安装流程摘要

```bash
# 1. 克隆 GPT-SoVITS
cd /opt && git clone https://github.com/RVC-Boss/GPT-SoVITS.git && cd GPT-SoVITS

# 2. 创建 Python 环境
conda create -n sovits python=3.10 -y && conda activate sovits

# 3. 安装 PyTorch（CUDA 12.1 示例）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt

# 4. 安装 FFmpeg
sudo pacman -S ffmpeg    # Arch
# sudo apt install ffmpeg  # Debian/Ubuntu

# 5. 训练语音模型
python webui.py    # 浏览器打开 http://localhost:9871

# 6. 启动 API
python api.py \
  -s logs/yachiyo/yachiyo_e8_s200.pth \
  -g logs/yachiyo/yachiyo-e15.ckpt \
  -dr resources/reference_audio/yachiyo_ref.wav \
  -dt "你好，我是八千代辉夜姬" -dl zh \
  -a 0.0.0.0 -p 5000
```

### 8.3 与 Yachiyo 对接

`config/config.yaml` 中：

```yaml
gpt_sovits:
  enabled: true
  api_endpoint: "http://localhost:5000"  # 或 GPU 服务器地址
```

### 8.4 没有 GPU 怎么办

- CPU 推理约 10x 慢，不适合实时场景
- 将 GPT-SoVITS 部署在**独立 GPU 服务器**，后端通过内网 HTTP 调用
- 或暂时禁用：`gpt_sovits.enabled: false`

## 10. 常见问题

### Q: 后端连不上数据库

1. PostgreSQL 是否运行：`docker compose ps postgres`
2. `config.yaml` 密码是否与 `docker-compose.yml` 一致
3. Docker 模式 host = `postgres`，裸机 host = `localhost`

### Q: 前端无法调用 API

检查 `VITE_API_BASE_URL` 和 Nginx 代理配置

### Q: WebSocket 连接失败

1. Nginx `/ws` 路径配置
2. Cloudflare → Network → WebSockets 已开启
3. 前端使用 `wss://` 协议

### Q: Docker 构建后端很慢

C++ 编译需要 ≥4GB RAM。OOM 时：`docker compose build --no-cache backend`

### Q: Cloudflare 报 522/524 错误

防火墙开放 80/443，Nginx 和后端正在运行

## 总体流程

```
克隆代码 → 配置 .env → 确保 OpenClaw 可达 → (可选) 部署 GPT-SoVITS → docker compose up -d
```

核心依赖只有 **OpenClaw Gateway** 一个外部服务。GPT-SoVITS 是可选的，不部署也能正常使用文字+动画。

---

## 1. 环境准备

```bash
# Docker
sudo pacman -S docker docker-compose  # Arch
# 或: sudo apt install docker.io docker-compose-v2  # Ubuntu

# 启动 Docker
sudo systemctl enable --now docker

# 验证
docker --version      # ≥ 20.10
docker compose version # ≥ v2
```

---

## 2. 配置 .env

在项目根目录创建 `.env` 文件（已在 `.gitignore` 中，不会被提交）：

```bash
cat > .env << 'EOF'
# ============ 必填 ============

# JWT 签名密钥 — 随机生成 ≥32 字符
JWT_SECRET_KEY=$(openssl rand -base64 32)

# PostgreSQL 密码
DB_PASSWORD=choose-a-strong-password

# ============ OpenClaw Gateway（必填）============

# OpenClaw Gateway 访问地址
# 如果 OpenClaw 和该项目在同一台机器上且用 Docker:
OPENCLAW_ENDPOINT=http://host.docker.internal:8100
# 如果是远程 OpenClaw:
# OPENCLAW_ENDPOINT=http://192.168.1.100:8100

# OpenClaw 认证令牌
OPENCLAW_GATEWAY_TOKEN=your-openclaw-gateway-token

# 模型选择
OPENCLAW_MODEL=deepseek/deepseek-v4-flash

# ============ GPT-SoVITS（可选）============
# SOVITS_ENDPOINT=http://localhost:5000
EOF
```

## 3. 对接 OpenClaw（必选）

OpenClaw Gateway 处理三项工作：**内容审查 → AI 对话 → 日语翻译**，一次 API 调用完成。

### 3.1 确认连通性

```bash
curl http://localhost:8100/v1/models
# 或远程地址
curl http://<openclaw-ip>:8100/v1/models
```

如果有认证，加上 header：
```bash
curl -H "Authorization: Bearer <token>" http://localhost:8100/v1/models
```

预期返回模型列表 JSON。

### 3.2 测试 AI 回复

```bash
curl -X POST http://localhost:8100/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -H "x-openclaw-model: deepseek/deepseek-v4-flash" \
  -d '{
    "model": "openclaw/default",
    "messages": [
      {"role": "user", "content": "你好"}
    ],
    "max_tokens": 100
  }'
```

### 3.3 System Prompt 位置

`backend/config/yachiyo_system_prompt.txt` — Docker 启动时自动挂载到容器内 `/app/config/`。

这个文件定义了八千代的人设和 JSON 输出格式。如果需要调整角色性格或输出格式，改这个文件即可，不需要改代码。

## 4. 对接 GPT-SoVITS（可选）

GPT-SoVITS 提供日语语音合成。不部署时，系统只推文字+Live2D 动画。

### 4.1 前提

已完成 GPT-SoVITS 模型训练（参考 `docs/GPT-SoVITS部署指南.md`）。

需要从训练机拷贝：

```
训练产物:
  yachiyo_eX_sXXX.pth    (~130MB SoVITS 模型)
  yachiyo-eXX.ckpt       (~150MB GPT 模型)
  yachiyo_ref.wav        (3~10秒参考音频)

预训练基础模型 (从 HuggingFace 下载或训练机拷贝):
  s1bert25hz-2kh-longer-epoch=68e-step=50232.ckpt  (~150MB)
  s2D488k.pth                                       (~90MB)
  s2G488k.pth                                       (~100MB)
```

### 4.2 安装 GPT-SoVITS

```bash
cd /opt
git clone https://github.com/RVC-Boss/GPT-SoVITS.git
cd GPT-SoVITS
python -m venv venv
source venv/bin/activate

# CPU 模式 (Arch Linux)
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
sudo pacman -S ffmpeg
```

### 4.3 放置模型文件

```bash
# 训练产物
cp yachiyo_e8_s328.pth /opt/GPT-SoVITS/models/
cp yachiyo-e15.ckpt /opt/GPT-SoVITS/models/

# 参考音频
mkdir -p /opt/GPT-SoVITS/reference
cp yachiyo_ref.wav /opt/GPT-SoVITS/reference/

# 预训练基础模型
cp s1bert25hz-*.ckpt /opt/GPT-SoVITS/GPT_SoVITS/pretrained_models/
cp s2D488k.pth /opt/GPT-SoVITS/GPT_SoVITS/pretrained_models/
cp s2G488k.pth /opt/GPT-SoVITS/GPT_SoVITS/pretrained_models/
```

### 4.4 启动 API

**关键：参考音频文本和语言必须与实际文件一致**

```bash
cd /opt/GPT-SoVITS
source venv/bin/activate

# CPU 模式
CUDA_VISIBLE_DEVICES="" python api.py \
  -s models/yachiyo_e8_s328.pth \
  -g models/yachiyo-e15.ckpt \
  -dr reference/yachiyo_ref.wav \
  -dt "スワイプしようとしているそこの君もう遅い時間だよ" \
  -dl "ja" \
  -a 0.0.0.0 \
  -p 5000
```

**参数说明**：

| 参数 | 含义 | 注意 |
|------|------|------|
| `-s` | SoVITS 模型路径 | |
| `-g` | GPT 模型路径 | |
| `-dr` | 参考音频路径 | 3~10 秒清晰人声 |
| `-dt` | 参考音频对应的文本 | 必须和音频内容一致！ |
| `-dl` | 参考音频语言 | `ja`(日语) / `zh`(中文) |
| `-a` | 监听地址 | `0.0.0.0` 允许外部访问 |
| `-p` | 监听端口 | 默认 5000 |

### 4.5 验证

```bash
# 健康检查
curl http://localhost:5000/

# 测试合成
curl -X POST http://localhost:5000/synthesize \
  -H "Content-Type: application/json" \
  -d '{"text":"こんにちは、八千代です","text_language":"ja"}' \
  --output test.wav

ffplay test.wav  # 听效果
```

### 4.6 加入 docker-compose（推荐）

在 `.env` 中取消注释：
```bash
SOVITS_ENDPOINT=http://gpt-sovits:5000
```

## 5. 启动服务

### 5.1 最小部署（无 TTS）

```bash
docker compose up -d postgres redis backend frontend nginx
```

### 5.2 含 TTS 部署

```bash
# 先启动 GPT-SoVITS API (非 Docker)
cd /opt/GPT-SoVITS && source venv/bin/activate
CUDA_VISIBLE_DEVICES="" python api.py ... &

# 再启动 Yachiyo
cd ~/yachiyoooooooo
docker compose up -d
```

### 5.3 查看日志

```bash
docker compose logs -f backend
docker compose logs -f frontend
```

## 6. 验证与排错

### 6.1 验证步骤

```bash
# 1. 后端健康检查
curl http://localhost:8080/api/v1/health
# → {"status":"ok","version":"1.0.0"}

# 2. 前端可访问
curl -I http://localhost:3000

# 3. WebSocket 端口
ss -tlnp | grep 9001

# 4. 注册用户
curl -X POST http://localhost:8080/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"test","email":"test@test.com","password":"Test1234!"}'

# 5. 登录
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"test","password":"Test1234!"}'

# 6. GPT-SoVITS (如果部署了)
curl http://localhost:5000/
```

### 6.2 常见问题

| 问题 | 检查 |
|------|------|
| 后端启动失败 | `docker compose logs backend` 查看是否有 OpenClaw 连通性 warn |
| WebSocket 连不上 | 检查 9001 端口、防火墙、Nginx 配置 |
| AI 回复为空 | OpenClaw Gateway 是否可达、token 是否正确、System Prompt 是否挂载 |
| 语音不播放 | GPT-SoVITS 是否运行、`SOVITS_ENDPOINT` 是否正确 |
| Live2D 不显示 | `resources/live2d/` 文件是否完整、前端 Console 是否有 404 错误 |

### 6.3 完整的故障排查

参考 `docs/全链路运行思路分析.md` 中的「故障排查思路」章节。

## 7. 前端配置说明

### 可替换的静态资源

| 资源 | 路径 | 替换方式 |
|------|------|---------|
| 网站 Logo | `frontend/public/images/logo.svg` | 替换文件 |
| 页面背景 | `frontend/public/images/bg.jpg` | 替换文件 |
| Live2D 模型 | `resources/live2d/` | 替换整个目录下的模型文件 |

### 生产环境构建

```bash
cd frontend
npm install
npm run build
# 产出在 dist/ 目录
```

Nginx 配置已在 `nginx.conf` 中，包含前端静态文件服务、API 反向代理、WebSocket 代理。

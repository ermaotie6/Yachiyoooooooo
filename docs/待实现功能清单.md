   ├── yachiyo.8192/               ← 纹理文件夹
   │   └── texture_00.png
   ├── expressions/                ← 表情文件（需用 Cubism Editor 导出）
   │   ├── f_smile.exp3.json       ← ✅ 已有
   │   ├── f_sad.exp3.json         ← ✅ 已有
   │   ├── f_cry.exp3.json         ← ✅ 已有
   │   ├── f_squint.exp3.json      ← ✅ 已有
   │   ├── f_default.exp3.json     ← ❌ 需要创建
   │   ├── f_angry.exp3.json       ← ❌ 需要创建
   │   ├── f_surprised.exp3.json   ← ❌ 需要创建
   │   ├── f_confused.exp3.json    ← ❌ 需要创建
   │   └── f_thinking.exp3.json    ← ❌ 需要创建
   └── motions/                    ← 动作文件（需用 Cubism Editor 导出）
       ├── m_idle.motion3.json     ← 待机动作（必须）
       ├── m_greet.motion3.json    ← 打招呼

       ├── m_wave.motion3.json     ← 挥手
       └── m_think.motion3.json    ← 思考

3. **在 `yachiyo.model3.json` 中注册表情和动作**:
   ```json
   {
     "Expressions": [
       {"Name": "f_smile", "File": "expressions/f_smile.exp3.json"},
       {"Name": "f_sad", "File": "expressions/f_sad.exp3.json"}
     ],
     "Motions": {
       "m_idle": [{"File": "motions/m_idle.motion3.json", "FadeInTime": 0.5, "FadeOutTime": 0.5}],
       "m_greet": [{"File": "motions/m_greet.motion3.json", "FadeInTime": 0.3}]
     }
   }
   ```

4. **组件已封装好的接口（无需修改）**:
   - `setExpression(name)` — 切换表情（如 `'f_smile'`）
   - `playMotion(group, priority)` — 播放动作（如 `'m_greet'`）
   - `setSyncMouthOpenY(value)` — 口型同步（0~1）
   - `setEyeTrackingTarget(x, y)` — 眼球追踪
   - `setEyeOpen(left, right)` — 眼睑控制
   - `syncMouthFromAudio(analyserNode)` — 从 Web Audio 自动同步口型

5. **TTS 口型同步使用示例**:
   ```ts
   // 播放 TTS 音频时自动同步口型
   const audioCtx = new AudioContext()
   const source = audioCtx.createBufferSource()
   const analyser = audioCtx.createAnalyser()
   source.connect(analyser)
   analyser.connect(audioCtx.destination)
   // 将 analyserNode 传给组件
   live2dRef.value?.syncMouthFromAudio(analyser)
   source.start()
   ```

6. **SDK 授权**: Live2D Cubism SDK for Web 免费版仅限个人非商用，需确认使用范围

**涉及文件**: `OpenClawGateway.hpp/cpp`, `AvatarResponseService.hpp/cpp`  
**当前状态**: ⚠️ 架构调整  

**说明**: 对话生成功能 **不属于本项目职责**。本项目仅负责：
- 将审核通过的弹幕打包为 JSON 发给 OpenClaw
- 接收 OpenClaw 返回的回答文本 + 情感标签 + 动作指令
- 对回答进行后处理（翻译、TTS、Live2D 控制）

如需调整 AI 对话逻辑（prompt、模型选择等），请在 OpenClaw 侧修改。

`AIServiceImpl.cpp` 和 `AIController` 保留为辅助功能接口，可用于不经过 OpenClaw 的简单 AI 查询场景。

**涉及文件**: `backend/src/services/GPTSoVITSService.cpp`, `backend/include/services/GPTSoVITSService.hpp`  
**当前状态**: 已有完整的 HTTP 调用实现（真实 curl 路径 + mock fallback），支持 GPU/CPU 双模式推理、情感参考音频自动选择。

- 响应缓存避免重复合成

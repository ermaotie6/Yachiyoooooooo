# Yachiyo 项目 — 待实现功能清单

> 更新时间: 2025年  
> 说明: 以下列出项目中仍需完善的功能及其当前状态。邮件服务和文件存储功能已移除（项目不需要）。  
> 翻译服务已接入百度翻译 API + DeepSeek 备选；内容审核已接入 DeepSeek Chat API + 规则回退。

---

## ✅ 已完成集成

### 翻译服务 — 百度翻译 API + DeepSeek

**涉及文件**: `TranslationService.hpp/cpp`, `backend/config/config.yaml`, `config/config.yaml`  
**当前状态**: ✅ 已完成  
- 主引擎: 百度翻译 API（MD5 签名 + HTTP GET），支持自动检测语言
- 备选引擎: DeepSeek Chat Completion API（通过 prompt 翻译）
- 引擎优先级: Baidu → DeepSeek，自动故障切换
- 翻译缓存: 内存缓存 + 哈希键
- **用户操作**: 在 `backend/config/config.yaml` 中填入 `app_id` 和 `api_key`

### 内容审核 — DeepSeek Chat API

**涉及文件**: `DeepSeekModerationService.hpp/cpp`, `ModerationDTO.hpp`  
**当前状态**: ✅ 已完成  
- 主审核: 调用 DeepSeek Chat Completion API，返回结构化审核 JSON
- 回退方案: API 不可用时自动使用敏感词规则审核
- 类别: violence / adult / harassment / spam / hate / profanity
- 缓存 + 统计 + 情感验证
- **用户操作**: 在 `backend/config/config.yaml` 中填入 DeepSeek `api_key`

## 🔧 待实现功能

### 1. Live2D SDK 集成 (前端) — 需要用户亲自处理

**涉及文件**: `frontend/src/components/Live2DComponent.vue`  
**当前状态**: 组件框架已搭建，有表情/动作/口型同步的完整逻辑骨架，但所有 Live2D 渲染均为占位逻辑。  

**需要用户亲自处理的问题**:
1. **模型文件对齐**: `config/config.yaml` 中 `expression_map` 使用西文名 (`f_smile`) 而实际 `.exp3.json` 文件使用中文名 (`笑咪咪.exp3.json`)。需要：
   - 要么重命名模型文件为英文名
   - 要么修改 config.yaml 中的映射改成实际中文文件名
2. **缺少 .motion3.json 动作文件**: `motion_map` 中的动作 (`m_greet`, `m_nod` 等) 没有对应的 `.motion3.json` 文件，需要用 Live2D Cubism Editor 导出
3. **SDK 授权**: Live2D Cubism SDK for Web 有授权限制（免费版仅限个人非商用），需确认授权范围

**接口已就绪** (前端组件接口无需修改):
- `updateExpression(expression: string)` — 切换表情
- `updateMotion(motion: string)` — 播放动作  
- `updateMouthOpen(value: number)` — 口型同步
- `addAnimationCommand(cmd: AnimationCommand)` — 动画命令队列
- WebSocket 中 `AvatarResponse` 的 `emotions`/`actions`/`animation_commands` 字段直接驱动

**实现步骤**:
```bash
cd frontend
npm install pixi.js@7 pixi-live2d-display
# 在 Live2DComponent.vue 中初始化 PIXI.Application + Live2DModel.from()
# 将占位 Canvas 替换为 PIXI Canvas
```

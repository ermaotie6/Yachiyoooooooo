## ✅ 已完成

### 翻译服务 — 百度翻译 API + DeepSeek

**涉及文件**: `TranslationService.hpp/cpp`, `backend/config/config.yaml`  
**状态**: ✅ 已完成  

- 主引擎: 百度翻译 API（MD5 签名 + HTTP GET），支持自动检测语言
- 备选引擎: DeepSeek Chat Completion API（通过 prompt 翻译）
- 引擎优先级: Baidu → DeepSeek，自动故障切换
- **部署时操作**: 在 `backend/config/config.yaml` 中填入 `appid` 和 `api_key`

### 内容审核 — DeepSeek Chat API

**涉及文件**: `DeepSeekModerationService.hpp/cpp`, `ModerationDTO.hpp`  
**状态**: ✅ 已完成  

- 主审核: 调用 DeepSeek Chat Completion API，返回结构化审核 JSON
- 回退方案: API 不可用时自动使用敏感词规则审核
- **部署时操作**: 在 `backend/config/config.yaml` 中填入 DeepSeek `api_key`

## 🔧 待实现功能

### 1. Live2D SDK 前端集成 — 需要用户处理

**涉及文件**: `frontend/src/components/Live2DComponent.vue`  
**当前状态**: 组件框架已搭建，有表情/动作/口型同步的完整逻辑骨架，但渲染层为占位实现。  

**需要用户处理**:

1. **安装 Live2D SDK**:
   ```bash
   cd frontend
   npm install pixi.js@7 pixi-live2d-display
   ```

2. **在 Live2DComponent.vue 中接入 SDK**:
   - 初始化 `PIXI.Application` + `Live2DModel.from('yachiyo.model3.json')`
   - 将占位 Canvas 替换为 PIXI Canvas
   - 组件接口无需修改，已封装好:
     - `updateExpression(expression)` — 切换表情
     - `updateMotion(motion)` — 播放动作
     - `updateMouthOpen(value)` — 口型同步

3. **缺少的表情/动作文件**: 
   - `config.yaml` 中映射了 `f_default`, `f_angry`, `f_surprised`, `f_confused`, `f_thinking` 等表情，但目前只有 4 个 `.exp3.json` 文件
   - 动作文件 (`m_greet.motion3.json`, `m_nod.motion3.json` 等) 尚未创建
   - 需要用 **Live2D Cubism Editor** 导出对应的表情和动作文件

4. **SDK 授权**: Live2D Cubism SDK for Web 免费版仅限个人非商用，需确认使用范围

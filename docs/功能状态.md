## 已完成功能

| 模块 | 说明 | 涉及文件 |
| --- | --- | --- |
| 用户认证 | JWT 注册/登录/刷新/注销，SHA-256+Salt 密码加密 | `AuthServiceImpl`, `AuthController`, `JwtUtil` |
| 内容审核 | DeepSeek Chat API 语义审核 + 本地敏感词规则回退 | `DeepSeekModerationService`, `MessageServiceImpl` |
| 6 层安全审查 | 速率限制 → IP检查 → 关键词 → AI语义 → 行为分析 → 综合评分 | `MessageServiceImpl` |
| 翻译服务 | 百度翻译 API（主引擎） + DeepSeek LLM（备选），自动降级 | `TranslationService` |
| WebSocket 实时通信 | Crow WebSocket 服务器 (:9001)，消息广播到所有在线观众 | `WebSocketService`, `WebSocketController` |
| 消息持久化 | PostgreSQL 存储消息 + 审核状态 + 对话上下文 | `DatabaseService`, `MessageServiceImpl` |
| 用户服务 | 10 个方法全部通过 `DatabaseService::userDAO()` 查询 PostgreSQL | `UserService`, `DatabaseService` |
| 聊天服务 | 6 个方法通过 `messageDAO()` / `contextDAO()` 查询 PostgreSQL | `ChatService`, `DatabaseService` |
| Redis 缓存 | 速率限制、Token 黑名单、翻译缓存、TTS 缓存 | `DatabaseService` |
| WebSocket 端口统一 | 全部统一为 9001 端口（Nginx/Docker/代码/配置） | `nginx.conf`, `Application.cpp`, `config.yaml` |
| Live2D 文件英文化 | 所有模型文件重命名为英文（yachiyo.*） | `resources/live2d/` |
| 前端 UI | 字幕覆盖层、50 字输入限制、可替换 Logo/背景、Vite Live2D 资源代理 | `LiveStream.vue`, `App.vue`, `vite.config.ts` |
| 前端认证 | Token 自动刷新拦截器、未登录自动弹出登录对话框 | `api/client.ts`, `stores/auth.ts` |
| 监控系统 | Prometheus 指标采集 + Grafana 可视化 | `docker-compose.yml`, `prometheus.yml` |
| 测试 | 13 个单元测试 + 4 个集成测试（Google Test） | `backend/tests/` |

### Live2D 待补充的资源文件

当前已有的表情文件：`f_smile`, `f_sad`, `f_cry`, `f_squint`

还需要创建的文件（使用 Live2D Cubism Editor 导出）：

**表情文件** (放入 `resources/live2d/`):
- `f_default.exp3.json` — 默认表情
- `f_angry.exp3.json` — 生气
- `f_surprised.exp3.json` — 惊讶
- `f_confused.exp3.json` — 困惑
- `f_thinking.exp3.json` — 思考

**动作文件** (放入 `resources/live2d/motions/`):
- `m_idle.motion3.json` — 待机（必须）
- `m_greet.motion3.json` — 打招呼
- `m_nod.motion3.json` — 点头
- `m_shake.motion3.json` — 摇头
- `m_wave.motion3.json` — 挥手
- `m_think.motion3.json` — 思考

创建后需在 `yachiyo.model3.json` 中注册。

## 优先级建议

| 优先级 | 功能 | 理由 |
| --- | --- | --- |
| **P0** | OpenClaw 对话 | 核心功能，AI 对话由 OpenClaw 负责 |
| **P1** | Live2D 表情/动作资源补充 | 视觉核心，需要 Cubism Editor |
| **P2** | GPT-SoVITS 语音合成 | 增强体验，需要 NVIDIA GPU |

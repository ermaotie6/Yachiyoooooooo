# 静态图片资源

此目录存放可替换的静态图片资源。

## 文件说明

| 文件名 | 用途 | 建议尺寸 |
|--------|------|----------|
| `logo.svg` | 网站 Logo（头部导航栏显示） | 64×64 px |
| `bg.jpg` | 网站全局背景图片（可选，放置后自动生效） | 1920×1080 px 或更大 |

## 替换方法

- **替换 Logo**：将新的 Logo 文件命名为 `logo.svg`（或 `logo.png`）放入此目录即可。如果更换格式，需要同步修改 `App.vue` 中的 `<img>` 标签 `src` 属性。
- **替换背景**：将背景图片命名为 `bg.jpg` 放入此目录即可自动生效。支持 `.jpg`、`.png`、`.webp` 格式（需对应修改 CSS 中的文件名）。
